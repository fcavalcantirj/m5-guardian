Upstream source
  M5Stack, M5_Hardware repository, https://github.com/m5stack/M5_Hardware
  File: Products/K150_StickS3/Structures/StickS3.stl
  Inspected at repository commit 8231e759560ce63d864c8987b8ca12f9c09c825b
  (file last changed by commit 48baa75a9476f4070dd5f107c1c28e2c9f383a96,
  2026-07-15; git blob 5da93e9c27ee78cfc8a3586a8125d2bf2698cfef,
  734,884 B, sha256 cadfa88716cb74a85d0d76dc866d83dbd627d6f5c310b528d43e588dab37ecec).
  The upstream file is one binary STL ("STICKS3_ASM", 14,696 triangles)
  holding the StickS3 parts twice: once assembled and once laid out side by
  side.

Conversion
  The three files are the assembled copy split into its three connected
  parts (front shell 2,002 triangles, back shell 4,808, key mat 538) and
  moved by (-12, -24.08, +6.6) mm so the device is centred on the origin;
  units stay millimetres. The facet normals are written as zero (the viewer
  computes its own) and the 80-byte headers are blank. Nothing else changes:
  every triangle of each file equals an upstream triangle after that move,
  within 1e-6 mm (single-precision rounding).
  The split files were made for the owner's Doutor VPD website and copied
  unchanged from it; the comparison above was measured against the upstream
  file on 2026-11-22.

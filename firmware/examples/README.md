# API examples (G01)

Illustrations of the portable contracts in `components/guardian_core/include/guardian/` and `components/guardian_presenter/include/guardian/output.hpp`. Not flashed. Since G03, `headless_replay.cpp` is built and run by the host harness (`firmware/CMakeLists.txt` target `headless_replay`, ctest `headless_replay_runs`) against the real libraries. Since G05 it runs the real `SecurityFrameParser` (G04) and the real `observe_security()` / `Core` policy (G05) over the bytes of the `beacon_wpa3_sae_pmf_required` fixture embedded in the source (plus a PMF-optional variant), and ctest asserts the fresh -> unrated -> stale -> historical sequence. Since G06 it also runs the real `DisconnectDetector` / `BaselineDetector` over the same frames with an explicit `ApprovedScope` baseline (reset on the clock epoch change); the replay has no disconnect frames and a single differing beacon (below `change_threshold`), so the asserted `incident=0` is unchanged. The SDK sketch is not built by any target; its earlier reviewer syntax check is not linked/runtime proof.

| File | Shows | Caveat |
|---|---|---|
| `headless_replay.cpp` | the whole pipeline on a host with no SDK: fake clock (with a reboot), replay `FrameSource` with a `CoverageReport`, `SecurityFrameParser`, `observe_security()`/`observe_signal()`, `ApprovedScope` + `DisconnectDetector` + `BaselineDetector` (G06), `Core`, `present()`, stdout `StatusOutput`; linked and run by ctest | the frames are hand-assembled fixture bytes (`Origin::Imported`), never a capture; a passing run proves wiring and the host policy, not reception |
| `espidf_adapter_sketch.cpp` | how `boards/sticks3` will wrap `esp_wifi` promiscuous reception, a FreeRTOS queue and `esp_timer` behind `FrameSource` / `MonotonicClock`, and fill `BoardCapabilities` | sketch against pinned ESP-IDF v5.4 headers read this session; `passive_receive` remains Unknown until G13 proves reception on the unit |

The replay example preserves acquisition timing and is Imported, never live. The SDK sketch uses task-context queue calls and retains acquisition epochs. Neither implements the mandatory L02 automated host live harness. See [G01 validation](../../docs/G01-validation.md).
